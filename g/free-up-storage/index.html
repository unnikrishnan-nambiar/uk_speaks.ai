Storage

Free up space on your laptop, safely.

Claude Code finds what's eating your storage on a Mac or Windows laptop, cleans only what you approve, then makes it feel faster. It can't delete anything without your yes.

01

Step 1: Install Claude Code

You need a paid Claude plan (Pro or higher). On a Mac, open the Terminal app (press ⌘ Space and type “Terminal”). On Windows, open PowerShell from the Start menu. Copy the command for your laptop, paste it, press Enter, then close the window and open a new one.

Mac · Terminal

curl -fsSL https://claude.ai/install.sh | bash

Windows · PowerShell

irm https://claude.ai/install.ps1 | iex

02

Step 2: Start it in “look only” mode

In the new window, type cd ~ and press Enter, then type claude and press Enter. Sign in when it asks. Now press Shift + Tab until you see plan mode on. In plan mode Claude can look and report, but it can't change or delete anything.

03

Step 3: Ask for a storage check-up

Copy this prompt, paste it into Claude and press Enter. It works on Mac and Windows. Claude only reads file names and sizes, never what's inside your files.

Prompt 1 · Check-up

Help me free up storage on this laptop. First check whether it's a Mac or Windows. This is a READ-ONLY check-up: do not delete, move, rename or change anything, and don't run any command that writes to the disk. Look at file names and sizes only, never open my personal files. Skip system folders. 1) Show total disk size, used and free space. 2) List the 20 biggest folders and every file over 500 MB in my user folder. 3) Check the usual space hogs: Downloads, Desktop, Trash or Recycle Bin, app and browser caches, old iPhone/Android backups, installer files (.dmg .pkg .exe .msi .zip), duplicate files, big old videos, and developer leftovers like node_modules, Xcode or Docker if I have them. Give me ONE table sorted by size: number, item, location, size, what it is in plain English, safety (Safe / Check first / Keep) and how it would be removed. End with how much space I'd get back by removing only the Safe items.

04

Step 4: Clean up only what you approve

Press Shift + Tab until plan mode is off. Claude will now ask before every action, and you answer Yes or No each time. Then send this prompt with the numbers you're happy to remove, for example “2, 3, 4”.

Prompt 2 · Safe clean-up

Clean up only these items from your table: [NUMBERS]. Rules: 1) One item at a time, and tell me exactly what you're about to do before each action. 2) Move files to the Trash or Recycle Bin instead of deleting them permanently, so I can undo. Never use rm -rf, del /s, Remove-Item -Recurse -Force or anything that skips the Trash. 3) Where a built-in tool exists, use it instead: Storage settings on Mac, Disk Cleanup or Storage Sense on Windows, or the app's own "clear cache" option. 4) Never touch system folders, installed apps, my Photos library, iCloud/OneDrive/Google Drive folders, password managers or anything marked Keep. 5) If you're unsure about anything, stop and ask me. After each item, show how much space it freed. At the end, show free space before and now.

05

Step 5: Make it feel faster

Space is only half of it. Apps that start at login and apps hogging memory are what usually make a laptop slow. This prompt finds them and changes nothing until you agree.

Prompt 3 · Speed check

Now find out why my laptop feels slow. Read-only first: don't change any setting yet. Show me: apps that open automatically when I log in, the 10 apps using the most memory and CPU right now, how full my disk is (under about 15% free slows things down), whether system updates are waiting, how long since the last restart, and anything else unusual. Then suggest the 5 changes that will help most, easiest first, one line each in plain English. Only make a change after I say yes, and tell me how to undo it.

06

Step 6: Empty the Trash next week

Everything removed is still in your Trash or Recycle Bin, so nothing is lost yet. Use your laptop normally for a week. If nothing is missing, empty it to actually get the space back. Run Prompt 1 again every month or two.

Your safety net

  • Plan mode (Step 2) means Claude can only look and report.
  • With plan mode off, Claude still asks before every action. Read it, and say No if you're unsure.
  • Everything goes to the Trash or Recycle Bin first, so you can put it back.
  • Never approve anything in System, Windows, Program Files or Applications folders.
  • Back up first if you can: Time Machine on Mac, File History on Windows.
