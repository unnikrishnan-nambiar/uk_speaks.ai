Prompt 2 · Your first trade check

Use my day trader skills. Paper trading only: never place a real order. Scan for today's setups, check the news on the best 3, then plan the entry, stop and target for the best one. Run the Time Machine on it. Explain in simple English: how often this setup won, how often it lost, and the most I could lose.

What you get, free

One skill pack with 11 skills inside. Each one does one job, like a small trading team.

  • Scanner: looks through thousands of charts for setups.
  • Entry + Exit: when to get in, plus a stop and a target before you enter.
  • Time Machine: replays the trade 10,000 times so you see how often it wins and loses.
  • News + Alerts: tracks news on your stocks and tells you when a price, stop or target is hit.
  • Budget + Risk: sizes the trade to your money and blocks trades that break your limits.
  • Also: an earnings analyst, a congress trades tracker and an optional broker connection.

Full steps

01

Step 1: Open Claude Code

The skills run small Python tools, so they need Claude Code. Open it from the Claude desktop app (Code), or type claude in your terminal. Claude Code comes with a paid Claude plan (Pro or above).

02

Step 2: Install the skills

Paste Prompt 1. Claude downloads the pack and copies the 11 skills in. If it asks to install Python 3, say yes. No API keys needed.

Only use the link above. Copies of this repo with the same description have shown up on GitHub, and copies can hide harmful code.

03

Step 3: Scan and plan

Paste Prompt 2. Claude scans for setups, reads the news, then plans when to enter and where to exit.

04

Step 4: Read the Time Machine

It plays your trade out 10,000 times and also checks past days when the same setup showed up. If it loses more than it wins, skip it.

05

Step 5: Let Claude watch the news

Add your stocks and paste Prompt 3 each morning. If your Claude app has scheduled tasks, ask Claude to run it every day at 8 AM.

Prompt 3 · Morning news check

Use the trader news skill to check the last 12 hours of news for my watchlist: [TICKERS, e.g. NVDA, TSLA, AAPL]. In 5 short lines, tell me what could move each stock today and why. Facts only, no buy or sell advice.

Points to be noted

  • Not financial advice. The tools read public data and do maths. Most day traders lose money.
  • It covers US stocks (about 5,900), not Indian stocks.
  • Paper trading is the default. Stay there until you trust it.
  • The Time Machine is a reality check, not a prediction. It's built from about 60 days of 5-minute price data.
  • Price data comes from Yahoo Finance, which isn't an official feed and can lag.
  • Connecting a broker is optional. If you do, keep keys out of the chat and approve every order yourself.
  • The skills are free (MIT licence). Claude Code needs a paid Claude plan.
