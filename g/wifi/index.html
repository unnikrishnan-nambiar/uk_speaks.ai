Prompt · Fix my WiFi

My WiFi is slow. I pay for [X] Mbps. Find out why and fix it. Start by making a to-do list of these 7 steps and tick them off as you go. Explain everything in plain words and show results in short tables. 1. Run a speed test. Show a table of what I pay for vs what I'm actually getting, and what % of my plan that is. Also measure my ping and jitter. 2. Check this computer: which WiFi band I'm on (2.4 or 5 GHz), my DNS, VPN and power saving settings. Then show a table of the apps using the internet in the background right now: the app, how much it's using, and what it's doing. 3. Check my WiFi signal strength and which channel I'm on. 4. Find the devices on my network. Show a table with name, type and maker where you can tell. Ask me about any device you can't identify. 5. Scan nearby WiFi networks and show which channels are crowded and which are empty. 6. List the fixes you recommend, biggest impact first, and ask for my go-ahead before changing anything. Write down my current settings first so I can undo. 7. Apply only the fixes I approve, run the same speed test again, and show a before/after table. Rules: never ask me to type my router or WiFi password in this chat, tell me where to type it myself. If this is not my own home WiFi (hostel, office, college), skip steps 4 and 5 and any router changes, and only fix things on this computer.

Need help? Full steps

01

Step 1: Open the Code tab

Install the Claude desktop app on your Mac or Windows laptop and sign in. Click the Code tab at the top of the sidebar.

Under the message box, pick the Local environment, then Open folder… and choose any folder, for example Documents. Claude needs to run on your own laptop to test your WiFi.

02

Step 2: Set it to ask first

In the same row, set the permission mode to Manual. Then Claude asks you before it runs a command or changes a setting.

03

Step 3: Paste the prompt

Copy the prompt above, replace [X] with the speed on your WiFi bill (for example 100), and send it. Claude works through the 7 steps and shows each result in a small table.

04

Step 4: Change the channel

If your neighbours' WiFi is on the same channel as yours, Claude tells you which empty channel to move to.

Router changes need your router login. Claude tells you the address (often 192.168.1.1, or your provider's app). Type the password there yourself. It's usually on a sticker under the router.

05

Step 5: Test again

After the fixes, Claude runs the same speed test and shows you a before and after table, so you can see what actually changed.

Points to be noted

  • The Code tab needs a paid Claude plan (Pro or higher). The free plan can't run checks on your laptop.
  • Results depend on your home. If the slowdown comes from your provider or an old router, Claude will tell you that instead.
  • Say yes only to changes you understand. Claude writes down your old settings first so you can undo them.
  • On hostel, office or college WiFi, only the laptop fixes apply. Don't change shared routers.
  • Never paste your router or WiFi password into the chat.
