Prompt · Fix my WiFi

My WiFi is slow. I pay for [X] Mbps. Find out why and fix it. Start by making a to-do list of these 7 steps and tick them off as you go. Explain everything in plain words and show results in short tables. 1. Run a speed test. Show a table of what I pay for vs what I'm actually getting, and what % of my plan that is. Also measure my ping and jitter. 2. Check this computer: which Wi-Fi band I'm on (2.4 or 5 GHz), my DNS, VPN and power saving settings. Then show a table of the apps using the internet in the background right now: the app, how much it's using, and what it's doing. 3. Check my Wi-Fi signal strength and which channel I'm on. 4. Find the devices on my network. Show a table with name, type and maker where you can tell. Point out the ones that don't look like mine, then ask me which ones to keep, with options I can click. 5. Scan the nearby Wi-Fi networks. Show a table of each network's channel and signal, tell me how many share my channel, and which channel is emptiest. 6. Put every fix in one list, grouped into: On this computer, On my router, and Devices on my Wi-Fi, with how many changes are in each group. Then ask me with clickable options: Yes, make all of them / Let me choose / Not now. Don't change anything before I answer. 7. If I say yes, first write down the current value of everything you'll change so I can undo it. Then make the changes, run the same speed test again, and show a before/after table with download, ping and jitter. Rules: use the tools already on my computer where you can. If you need an admin password or a permission, ask me. For router changes, open my router's admin page and let me type the password myself. If my router can only be changed in my provider's app, give me exact steps instead. Never pause, quit or block anything without my yes.

Points to be noted

  • The Code tab needs a paid Claude plan (Pro or higher).
  • Use the Claude desktop app on a laptop. In normal Claude chat (website or phone app), Claude can't test your WiFi. It can only give advice.
  • Router changes: Claude opens your router page. Type the password yourself (usually on a sticker under the router).
  • On hostel, office or college WiFi, only the laptop fixes apply.
